# Site du camping Clairac

Site statique Eleventy 3 (gabarit Glimra), thème `src/assets/themes/clairac.css`.
- Contenu : `src/_data/*.json` (site, accueil, tarifs, faq, alentours) et `src/pages/`.
- `npm run dev` (aperçu), `npm run build` (sortie `_site/`).
- Publication : Vercel (réglages dans `vercel.json`). `site.json > demo: true` = bandeau démo + noindex ; passer à false à la mise en ligne.
- Lire `DESIGN.md` et `SEO.md` avant de modifier le design ou le référencement.
